### Requirements

Build on the Photon 2.0 beta and ship where people already live:

- [Photon 2.0 beta](https://photon.co/beta) - Photon’s open source framework that brings agents to every messaging channel. Sign up at the [dashboard](https://app.photon.codes/dashboard), create a project, and add the channels you want. No promo code needed: the beta is free to use.
- **Texting:** connect your agent to iMessage through the dashboard, and add SMS, RCS, WhatsApp, Telegram, or email if you want more reach. iMessage is still the flagship channel for text agents.
- **Voice:** phone calls run on an SMS number, not on iMessage. Add an SMS number to your project, set up a Voice profile, and connect it over SIP to Retell, ElevenLabs, LiveKit, or Twilio. Calls and group chat on iMessage both need a dedicated iMessage line, so for the hackathon, build voice on SMS.
- Docs: [Photon 2.0 beta docs](https://photon.codes/docs/beta/api-reference) (still being written) and [cookbooks](https://photon.codes/docs/beta/cookbooks) with step-by-step voice setup for [Retell](https://photon.codes/docs/beta/cookbooks/voice/retell), [ElevenLabs](https://photon.codes/docs/beta/cookbooks/voice/elevenlabs), [LiveKit](https://photon.codes/docs/beta/cookbooks/voice/livekit), and [Twilio](https://photon.codes/docs/beta/cookbooks/voice/twilio). SDK reference: [https://photon.codes/docs/spectrum-ts/introduction](https://photon.codes/docs/spectrum-ts/introduction)

> To qualify for the prize, **your project must be built on Photon 2.0 and live on at least one Photon channel.** iMessage is home base for text agents; voice agents live on an SMS number.

### What great looks like

- Real human-in-the-loop collaboration, not a demo reel of prompts
- Context-awareness that persists across time, channels, and teammates
- A delightful default: the agent elevates the moment without demanding attention
- Thoughtful safety and fallback behaviors that earn trust
- For voice agents: natural turn-taking, low latency, and an agent that remembers the call when the conversation moves back to text

---

### Judging

- Vision: Does this push the frontier of **hybrid intelligence**?
- Craft: Is it cohesive, **responsive**, and tastefully integrated?
- Depth: How well does it handle **real-world context** and edge cases?
- Traction: Can we imagine this running with **real users** tomorrow?
